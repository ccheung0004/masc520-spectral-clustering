# IMathAS Audit Policy Addendum v1.0

**Status:** Approved user ruling  
**Effective:** 2026-10-15  
**Affected rubric row:** Question Flow — Context & variation  
**Scope:** Pure definition and conceptual items; all other templates retain the existing variation standard.

## 1. Binding ruling

Pure definition and conceptual items are **exempt from the minimum of 10 meaningful variations**.

For these exempt items, Context & variation is a finding **only if the template is hardcoded**, meaning that no generated content changes between seeds. For a multiple-choice item, a hardcoded template displays the same single set of options on every seed. Reordering the same options by shuffling does not constitute variation.

If a pure definition or conceptual item is hardcoded, assign **Context & variation [B]**, and **Question Flow scores 0**.

In every other case involving an exempt item, **do not report variation at all**: no defect and no informative note.

## 2. Non-exempt templates

The existing requirement for **at least 10 meaningful variations** continues to apply to all other templates, including numeric items. Existing definitions, exclusions, severity bands, and scoring rules for these non-exempt templates remain unchanged.

## 3. Applicability and precedence

This addendum supersedes earlier universal-variation language **only insofar as it would impose the 10-variation minimum on pure definition and conceptual items**. It does not modify any other rubric row or other audit requirement.

Use the source exercise and actual graded task to determine whether an item is a pure definition or conceptual item. Do not assume exemption merely because the item is multiple choice; a numerical, computational, or application task remains non-exempt.

Apply this ruling in all subsequent Hunter, consolidator, triage, and presentation workflows. If an earlier audit charged an exempt item solely for having fewer than 10 meaningful variations despite non-hardcoded content, treat that variation finding as superseded under this ruling. Do not silently alter other audit findings or historical benchmark records.

## 4. Application example: Blitzer §4.5, Exercise 60

The half-life definition MCQ has multiple distinct option sets across seeds (previous audit enumeration: 48 sets). It is not merely shuffling one fixed set. As a pure conceptual-definition item, it is **not hardcoded** under this ruling.

**Result:** Do not report a Context & variation finding or informative note for this item. The previous variation-based [B] verdict and consequent Question Flow zero are superseded; any updated score must be recomputed using the remaining applicable findings and scoring rules.

## 5. Outstanding matters — not decided here

This addendum makes **no ruling** on (a) whether a sentence may be split across physical lines around a displayed calculation, or (b) which ordinary synonyms count as departures from required textbook terminology. Those questions require separate owner decisions if clarification is needed.
